# Bend agent router

Load one route, not the whole guide.

GATE
Use for manifests, receipts, admission, local commits, and reconciliation.
Read: guide/agent/GATE.md.

VERIFY
Use for setup, focused checks, proof correspondence, and evidence freshness.
Read: guide/agent/VERIFY.md.

RELEASE
Use for publication, host inspection, remote-tree comparison, and CI watching.
Read: guide/agent/RELEASE.md.

PROGRAM
Use for implementation, compilation, runtime, IO, tests, and ordinary Bend code.
Read: guide/agent/PROGRAM.md when present.

PROVE
Use for LAWS.bend, PROOF.bend, equality, induction, rewrite, contradiction, witnesses, and proof repair.
Read: guide/agent/PROVE.md when present.

FULL
Use guide/GUIDE.md only when PROGRAM or PROVE cannot answer a material question, or when language semantics themselves are under investigation.

Kernel boundary
Do not edit bend2/bend.ts for ergonomics changes. Escalate a theory edit only after the deletion test shows the task cannot be solved in routing, packs, CLI seams, compiler metadata, indexes, tests, or sidecars.
