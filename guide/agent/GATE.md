# Gate route

Read docs/admission.md, admission/api.py, and the exact failed domain's law or test.
Use ./repo demo for a disposable producer-to-commit example.
Use ./repo explain CODE for a stable decision explanation.
Use ./repo inspect-manifest FILE --compare OTHER to locate changed bindings.

The trusted controller supplies policy, keys, and repository mapping. A receipt
authenticates an assertion, not the execution that produced it. Do not widen the
evidence kind or edit policy to admit a failing candidate.

After uncertain execution, use ./repo reconcile REPOSITORY MANIFEST. Observation
does not grant retry authority. Preserve unresolved outcomes.
